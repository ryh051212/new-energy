# 魏都区充电设施规划基础数据：采集与质量报告

生成时间：2026-10-27T11:39:02.313877+00:00。执行日期按北京时间为2026-10-27。原始采集日期与对象更新时间分别记录，不用文件修改日期代替采集日期。

## 第一阶段：核心数据获取与验证

- 边界：复用项目 PostGIS 的 WGS84 研究边界，1个有效面，面积约90.1093平方公里。原始文件标记 AreaCity-Polygon，项目曾按GCJ-02转换；本次没有重新证明原始坐标基准或边界年代。政府简介面积89.3729平方公里，与项目相差约0.82%。因此保留原研究口径，不称其为最新法定勘界，不强行将栅格人口缩放到简介人口数。[政府简介](https://www.weidu.gov.cn/zjwd/walkIntoWD.html)
- 人口：已输出 **177 × 137** 像元 GeoTIFF，EPSG:4326；研究区中心约 **77.0 × 92.4 米**。有效像元 12668 个，区内 NoData 0 个，像元估计人数合计约 **892,503**。这是 GHSL 的2025预测人口，不是人口普查或手机实时人数，且边界像元没有面积比例分摊。 [官方产品说明](https://human-settlement.emergency.copernicus.eu/ghs_pop2023.php)
- POI：1993条，居住224、工作379、商业406、休闲222、公共服务762。高德原始类别、统一类别、来源ID及日期保留；商业类包含单独标明的餐饮子类，公共服务含学校和停车。POI不是人口、到访或充电次数。
- 道路：本次成功获取2987条OSM way，研究区外扩约10km；保留节点、道路类型、方向、通行标签、桥隧和转向限制。完整way可能延伸到查询矩形外，条数不是行政区内道路数量。`roads_within_boundary.geojson`只用于显示；路由应使用完整网络。
- 充电地点：247条真实地图地点，区内201条、周边46条；按来源ID去重。已排除项目内240条模拟站点CSV及演示补全字段。无法由名称推断运营商，也不把地图收录或数据库active标志当作对公众开放的证据。

人口模型的绝对总量存在明显的合理性待核问题：裁剪结果约89.25万人，高于政府简介不同段落约50万/52.5万的人口表述。简介本身的年份/口径混杂，现有边界年代也未确定，因此本次保留来源原值、记录差异，不把模型数称为魏都区官方常住人口，不据此直接计算绝对充电次数。充电地点中另有8条名称带重卡、公交、出租或换电等关键词，已逐条加scope_review_flags；这些只是名称线索，兼容私人乘用车和公共开放性须核实，不能全部作为默认供给。

高德结果存在明确缺口：周边充电查询报告594条，实际下载190个不同ID；政务交通查询报告600条，下载225个ID，之后API返回空页。原始查询结果和逐页日志已保存。本次停止在官方结果窗口，不采用分区查询规避额度；“翻到空页”不代表现实世界完整。既有POI类别同样存在结果窗口和平台收录偏差。

## 第二阶段：空间清洗和质量检查

- 所有正式矢量以WGS84经纬度导出。高德记录由明确GCJ-02输入迭代反算，保留原坐标系字段；OSM原生WGS84不重复转换。迭代往返可逆性检查不是地面控制点精度认证。
- 当前所有已导出矢量：空几何0、无效几何0、来源ID重复0；五类POI区外点0。充电文件的46个区外点是10km周边服务背景，不能作为裁剪错误删除。
- POI在30m内有485对邻近记录，充电地点有24对；逐对清单见metadata。不同ID、相近位置不一定是同一设施，因此只标疑似共址，不自动合并不同运营商。已完成来源ID去重，跨来源实体去重仍需人工复核。
- 站点属性缺失：运营商247/247、公众开放状态247/247、枪数247/247、全站装机功率247/247、对象更新日期247/247。仅2条站点有历史公开核对的桩台数、快充、最高单枪功率和开放时间；证据保留在field_evidence，不能把最高单枪功率乘桩台数作为全站容量。
- 路网包含16804个节点、28705条有向分段边；当前机动车通行情景保留28023条边，弱连通分量11个，最大分量节点占99.58%。强连通分量1482个，缺失端点0、非正长度边0。没有把平面相交道路自动连通，也未删掉小分量伪造连通。
- 2条转向限制和20个门禁/障碍节点已保留，尚未进入路径约束。全部28023条机动车情景边的通行属性未明确，因此“允许通行”是乐观情景假设，不是逐路核实。247个地点中有1个距离最近网络节点超过300m；即使距离较近，也不保证存在可通行车行入口。
- 速度表是按道路等级指定的自主情景参数，不是实时速度或法定限速。原始maxspeed仍保留；后续路由要执行限速上限、时段拥堵敏感性及转向/门禁约束。10km缓冲在80km/h下不足以保证穷尽10分钟路径，边缘地区应扩展到约15km或做缓冲敏感性检验。

## 第四阶段：文献观测和情景参数

论文作者Zenodo公开了支撑图表CSV，许可CC-BY-4.0。本次下载5个小型CSV并核对档案MD5。来源是2020年11月至2021年10月其他七座城市的车辆汇总；它们不是许昌数据，也不是个人轨迹。[作者数据](https://zenodo.org/api/records/13852045) [论文及2026更正入口](https://www.nature.com/articles/s44333-024-00023-3)

- `parameters/time_profiles.csv`：192条外部实测汇总，工作日与周末/节假日各96个15分钟区间，仅保留私人车。原始第96索引为24:00绘图端点，不重复算作一天的第97个区间。行驶、充电和停放三状态比例相加为1。这是时点状态比例，**不是开始充电概率、到达率或公共订单数**；充电包括私人和公共来源。
- 作者数据的私人车日充电次数中位数为0.4667次，不能直接当成0.4667的公共充电概率。原文数值与数据来自外地及较早时期，只作外部先验。
- 行业2022摘要的平均单次25.6kWh、49.3分钟包含混合公共平台用户，可能含营运车辆，未设为魏都区私人车默认值。IEA近75%的私人地点充电是场次占比，不能推成75%魏都区家庭可装家充。[能源局摘要](https://www.nea.gov.cn/2023-03/20/c_1310703965.htm) [IEA](https://www.iea.org/reports/global-ev-outlook-2026/electric-vehicle-charging-chap-6-and-10)
- `time_activity_assumptions.csv`：240条明确标为author_scenario_assumption的功能区小时活动权重；不是从订单或论文图形虚构提取的观测。`scenario_params.json`的区级车辆数、家充可用率、公共依赖率、日公共充电概率与电量均保持null；默认不启用绝对需求推算。

## 第五阶段：文件、复现和适用性

入口见README；机器质量报告见quality_report.json，来源清单见metadata/data_sources.csv，原始文件和请求日志见raw/及metadata/。包内提供独立GIS辅助函数和真实输入快照，不需修改现有应用数据库。可选PostGIS导入默认dry-run，只有显式--apply才写专用schema。未开发选址优化或输出未经校准的负荷图。

| 研究目标 | 当前判断 | 条件与限制 |
|---|---|---|
| 潜在公共充电需求空间分布 | 可做相对潜力/情景图 | 人口、功能POI可作空间基础；补齐家充条件和区级私人新能源车后才可讨论绝对量；需控制POI采集偏差与人口重复分配 |
| 工作日/周末分时估计 | 可做外部文献迁移情景 | 有真实外部15分钟状态曲线；尚无本地功能区到访或公共订单的小时规律 |
| 10分钟驾车可达性 | 具备路网准备条件，尚不是正式可用路径引擎 | 需处理2条转向限制、门禁、未明确通行、入口、速度及边界敏感性 |
| 公共服务薄弱区域 | 可做假设下的相对薄弱区初筛 | 站点开放性大多未知，需区分已记录地点与已核实公共供给；不能宣布真实需求未满足 |
| 真实充电负荷或设施容量 | 不支持 | 枪数、共享输出、配变容量、实时可用状态、排队/订单及本地车辆规模缺失 |

最值得补充的三项数据：①区级/分社区私人新能源车数量与家充可用性汇总；②运营商公共站点台账（对外开放、逐枪功率、共享功率、入口、开放时间及更新日期）；③匿名化小时公共订单与停车/到访时长，并同步取得道路分时速度或交通调查用于校验。涉及轨迹只申请必要汇总，不以其他城市的曲线代替本地实测。
