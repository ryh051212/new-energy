# 新增充电站优化清单

更新日期：2026-10-24。实现版本：`road-planning-v1`。

## 一、已确定的主线

```text
① 空间供需选择需求情景与站点基准
   → 需求模拟 → OSM 道路时间 → 现状覆盖、容量服务与缺口
↓
② 布局规划
   ├─ 地图手工新增：原始坐标保持不变
   └─ 自动选址：共同场地候选 → 加权需求聚类 / MCLP 逐轮选站
↓
③ 重新计算整个方案
   → 覆盖 → 时间 → 容量服务 → 原最弱 20% 需求与空间公平
↓
④ 对照方法、站数、时间阈值、需求情景及权重
   → 导出 CSV、完整 JSON → 版本校验后复算
```

- 保留空间供需、布局规划两个主页面；车网协同、双碳评估入口继续保留。
- 正式研究默认已记录站点，虚拟站只在独立演示模式使用。
- 覆盖选址、容量评价双主线；不把容量或公平性偷偷加进 MCLP 的加权目标。
- 已有站采用独立统一容量情景，默认每站 1 桩 × 60 kW；新站用草稿配置，配置不同会显示配置调整情景。
- 不修改真实站点数据库。旧直线模型放进辅助参考，不能与道路分钟结果混用。

## 四、接口与复算口径

三个接口均需有效会话：

| 接口 | 用途 |
|---|---|
| `POST /api/planning/analyze` | 现状、手工新增与移除方案 |
| `POST /api/planning/optimize` | 共同候选池上的自动选址 |
| `POST /api/planning/experiments` | 方法、数量、时段、阈值和权重实验 |

共同参数：`scenarioId`、`activityWeights`、`dataScope`、`thresholdMinutes`、`capacityScenario`、`constraints`、`factors`、`additions`、`removedIds`、`manualCandidates`。

自动参数：`method=mclp|kmeans|demand`、`requestedCount`。实验参数：`experimentType=methods|counts|thresholds|scenarios|weights`、`experimentMode=reoptimize|fixed`。

返回 `before/after/changes`、`grids/places/candidates/selectedStations/baselineStations` GeoJSON、`selection` 逐轮收益、`quality` 路网与缺失情况、`versions` 和 `baselineKey`。JSON 载入时复核 `baselineKey`，数据变化返回 409。

道路覆盖条件为 `时间 ≤ 阈值`。重复覆盖只计一次。需求未接入和道路不可达都保留在覆盖分母；只要存在正权重需求无有限时间，全区平均为 `null`，另外提供可达部分均值及不可达比例。界面不把可达部分均值冒充全区均值。

容量计算采用时间衰减 G2SFCA。指数使用基准服务均值归一为 100；当现状无服务时使用每站情景容量/总需求作为固定标尺。加站不承诺每个地点的容量服务或不均衡指标都改善。

MCLP 覆盖、时间均无收益时停止。数量不足会返回实际数量并标记不满足等数量对比，不凑数、不宣称全局最优。固定方案跨情景评价的入选频率不能作为重新选址稳定性的证据。

## 五、可继续修改的参数和研究边界

| 参数 | 默认值 | 后续调整位置 |
|---|---|---|
| 时段 | 工作日白天 | `planning_demand.SCENARIOS` / `functionalZones.js` |
| 时间阈值 | 10 分钟 | 网页研究设置，1～60 分钟 |
| 新增数量 | 最多 5 座 | 网页自动选址，1～20 座 |
| 容量情景 | 每站 1 桩 × 60 kW | 网页活动权重与容量设置 |
| 道路吸附上限 | 200 m | `planning_network.py` |
| 时间成本 | motorway 80、trunk 60、primary 40、secondary 35、tertiary 30、residential 20、living_street/service 10 km/h；其他支持道路 20；连接道不超过 30 | `SPEEDS`，已有有效限速作为上限 |
| 信号节点延时 | 20 秒 | `planning_network.py`，属于情景假设 |
| 弱势需求群体 | 基准容量服务最弱的需求权重 20% | `planning_engine.py`；前后冻结同组 |

- 网络沿用现有 OSM 研究区外衔接道路快照；当前源快照约含区外 2 km 范围，不代表完整城市道路。
- OSM 未记录的出入口、通行限制、转向限制不能视为已经核实。via-way、条件或例外转向限制未应用时计入质量报告，不冒充已支持。
- 容量、速度与需求权重均为情景参数，不代表实际订单、排队、收入、实时车速或电网余量。
- 真实预算优化、配网定容、订单校准、驾车加步行两阶段模型留作后续扩展。
