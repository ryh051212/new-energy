# 魏都区私人充电设施模拟方法与情景参数说明 v1

## 1. 文档目的

本文档说明魏都区私人充电设施情景数据的生成方法、数据来源、计算公式、低中高情景含义、输出字段和使用限制。

必须首先明确：本项目没有取得魏都区逐户私人充电桩登记数据。当前成果属于**住宅 POI 聚合尺度的情景模拟**，不能表述为“已获取魏都区私人充电站真实数据”。住宅 POI 的名称、地址和坐标来自项目既有数据；私人桩数量、功率、使用次数、费用等属性均为模拟值。

生成脚本：[`scripts/generate-private-charging-simulation.mjs`](../../scripts/generate-private-charging-simulation.mjs)

## 2. 完整执行流程

```text
① 读取住宅POI
   public/geojson/residential-pois.json
   输入：住宅名称、地址、类别、GCJ-02坐标
   ↓
② 将住宅点匹配到网页六边形
   ├─ 点位落在六边形内 → 使用该六边形grid_id
   └─ 未落入任何六边形 → 使用最近六边形中心作为回退
   ↓
③ 按grid_id读取人口投影属性
   data/processed/planning-baseline/population-grid.geojson
   ↓
④ 在六边形内部进行人口守恒分配
   同一六边形人口按住宅规模权重分给内部住宅POI
   ↓
⑤ 用情景户均人口将分配人口换算为家庭数量代理
   ↓
⑥ 设置低、中、高公共充电需求情景
   ↓
⑦ 计算每个住宅聚合点的私人桩数量
   ↓
⑧ 拆分7kW、11kW交流桩并计算装机容量
   ↓
⑨ 计算每日私人充电次数与充电量
   ↓
⑩ 接入工作日、周末24小时充电开始时间曲线
   ↓
⑪ 检查重复、情景单调性、时间曲线合计和公式错误
   ↓
⑫ 输出CSV、Excel与项目托管数据
```

## 3. 输入数据与空间口径

| 输入 | 文件 | 用途 | 数据性质 |
|---|---|---|---|
| 住宅 POI | `public/geojson/residential-pois.json` | 提供住宅名称、地址和空间锚点 | 项目已有采集数据，坐标为 GCJ-02 |
| 网页六边形 | `public/geojson/hex-grid.json` | 承接住宅点与 `grid_id` | 项目分析网格，GCJ-02 |
| 人口六边形 | `data/processed/planning-baseline/population-grid.geojson` | 提供人口投影数量 | 2025 年人口投影，未做魏都区统计总量校准 |

住宅 POI 与网页六边形均为 GCJ-02，因此点在面判断在同一坐标系中完成。人口六边形与网页六边形通过相同的 `grid_id` 关联，不直接混用 WGS84 与 GCJ-02 几何进行空间叠加。

每一条输出记录代表某个住宅 POI 所关联的小区或居住设施内的私人充电设施**聚合量**，不代表精确住户门牌、具体停车位或单个私人充电站。

## 4. 六边形人口分配

如果一个六边形内存在多个住宅 POI，不能把该六边形的全部人口重复赋给每个住宅点。项目采用人口守恒分配：

\[
P_i=P_h\frac{W_i}{\sum_{j=1}^{n}W_j}
\]

其中：

- \(P_h\)：六边形 \(h\) 的人口投影数量；
- \(P_i\)：分配给住宅点 \(i\) 的人口代理量；
- \(W_i\)：住宅点 \(i\) 的规模权重；
- \(n\)：六边形内住宅 POI 数量。

规模权重由住宅名称关键词与固定种子扰动共同组成：

- “小区、花园、家园、新城、名苑”等词对应相对较高权重；
- “家属院、宿舍”等词对应相对较低权重；
- 权重用于分配人口，不等于真实建筑面积或真实户数。

## 5. 家庭数量代理

分配人口通过情景户均人口转换为家庭数量代理：

\[
H_i=\frac{P_i}{2.7}
\]

其中 2.7 人/户为第一版研究者情景参数，不是魏都区实测户均人口。若后续取得魏都区或街道级家庭户数据，应替换该参数并重新运行脚本。

## 6. 私人充电桩数量模型

住宅点 \(i\) 在情景 \(s\) 下的私人充电桩数量为：

\[
C_{i,s}=H_i\times E_s\times F_{i,s}\times I_{i,s}
\]

其中：

- \(C_{i,s}\)：私人充电桩模拟数量；
- \(H_i\)：家庭数量代理；
- \(E_s\)：新能源汽车家庭渗透率；
- \(F_{i,s}\)：局地固定车位比例；
- \(I_{i,s}\)：局地私人桩报装成功率。

局地固定车位比例和报装成功率由全区情景参数乘以住宅点局地因子得到，并设置合理上下限。局地因子由住宅 POI 编号、模拟版本号和 SHA-256 固定种子生成。因此同一版本重复运行可得到相同结果，不同住宅点之间又保留差异。

固定种子扰动仅用于构造可复现的空间敏感性情景，不代表问卷调查、物业登记或实地抽样结果。

## 7. 低、中、高情景重新设计

本项目的低、中、高表示**公共充电需求水平**，不是私人充电桩数量水平。

| 参数 | 低公共充电需求 | 中等公共充电需求 | 高公共充电需求 |
|---|---:|---:|---:|
| 新能源汽车家庭渗透率 | 0.11 | 0.14 | 0.17 |
| 固定车位比例 | 0.72 | 0.55 | 0.36 |
| 私人桩报装成功率 | 0.82 | 0.65 | 0.45 |
| 公共充电依赖比例 | 0.22 | 0.42 | 0.65 |
| 私人桩每日充电概率 | 0.30 | 0.33 | 0.36 |
| 单次平均充电量（kWh） | 18 | 20 | 22 |
| 7 kW 交流桩比例 | 0.92 | 0.85 | 0.78 |
| 11 kW 交流桩比例 | 0.08 | 0.15 | 0.22 |
| 公共需求整体倍率 | 0.72 | 1.00 | 1.32 |

三种情景的解释如下：

```text
低公共需求
→ 固定车位条件较好
→ 私人桩报装成功率较高
→ 更多车辆可在住宅内部充电
→ 对公共充电站依赖较低

高公共需求
→ 新能源汽车家庭比例可能更高
→ 固定车位、配电容量和报装条件相对受限
→ 私人充电设施覆盖不足
→ 更多车辆依赖公共充电站
```

这些参数是研究者设置的敏感性参数。公开政策和外地论文只用于约束方向与范围，没有被直接当作魏都区实测概率。

## 8. 功率、开放状态和费用

私人设施统一设置为：

| 字段 | 当前定义 |
|---|---|
| 开放状态 | `not_open_to_public`，不对公众开放 |
| 使用权限 | `private_resident_authorized_only`，仅授权住户使用 |
| 可用时间 | 授权车主 00:00—24:00 可用，不表示对公众营业 |
| 充电功率 | 7 kW 交流为主，11 kW 交流为辅 |
| 服务费 | 0 元/kWh；私人自用场景不单列公共运营服务费 |
| 居民电价 | 未采集魏都区逐户账单，不填具体电价 |
| 安装费用 | 研究者模拟的设备与基础施工费用，只用于敏感性讨论 |

站点聚合装机容量为：

\[
K_{i,s}=7C_{7,i,s}+11C_{11,i,s}
\]

该值是所有模拟私人桩额定功率之和，不是住宅小区同时最大负荷。进行配电网分析时还需要加入同时率、有序充电、变压器容量和充电持续时间。

## 9. 每日充电次数与电量

每日私人充电次数：

\[
N_{i,s}=C_{i,s}\times p_s
\]

每日私人充电量：

\[
E_{i,s}=N_{i,s}\times e_s
\]

其中：

- \(p_s\)：私人桩每日发生充电的情景概率；
- \(e_s\)：情景单次平均充电量。

输出的次数允许带小数，含义是住宅聚合点的日均期望值，不是某一天必须发生的整数订单。

## 10. 24 小时开始时间曲线

工作日和周末分别保存 H00—H23 共 24 个小时比例，每行合计 100%。某住宅聚合点在小时 \(t\) 的私人充电开始次数为：

\[
N_{i,t,d}=N_{i,d}\times\frac{F_{t,d}}{100}
\]

其中 \(F_{t,d}\) 是对应日期类型下该小时占每日充电开始事件的百分比。

时间曲线依据公开家庭充电研究中“下班后、傍晚和夜间较集中”的规律构造。它是文献约束的初始代理曲线，不是魏都区私人桩订单曲线。低、中、高情景共用归一化曲线形状，情景差异由私人桩总量、每日充电概率和公共需求倍率控制。

## 11. 公共需求 Qk 参数

原居住 POI 强度已替换为人口强度，五类空间因子为：人口、工作、商业、休闲、公共服务/交通。第一版五类权重仍为：

\[
w_k=0.2
\]

重新设计的 \(Q_k\) 为探索性相对公共充电倾向系数：

| 场景 | 人口 | 工作 | 商业 | 休闲 | 公共服务/交通 |
|---|---:|---:|---:|---:|---:|
| 低公共需求 | 0.55 | 0.70 | 0.80 | 0.72 | 0.78 |
| 中等公共需求 | 0.80 | 0.95 | 1.10 | 0.90 | 1.00 |
| 高公共需求 | 1.20 | 1.25 | 1.45 | 1.20 | 1.30 |

\(Q_k\) 不是实际充电概率。商业场景保持较高相对值，用于表达目的地充电倾向；人口项则受到私人充电可用性的直接影响。

## 14. 复现方法

在 VS Code 中打开项目终端，确认当前目录为项目根目录，然后运行：

```powershell
node scripts/generate-private-charging-simulation.mjs
```

执行完成后，脚本会重新生成 CSV、汇总 JSON 和 README，并同步更新 `data/managed/scenario-v1/` 中的项目托管副本。

修改情景参数时，应修改脚本开头的 `scenarios` 数组，不应手工逐行修改 225 条设施记录。这样可以保留参数来源、版本号和可复现性。

## 15. 使用边界与后续校准

当前数据适用于：

- WebGIS 私人充电设施情景展示；
- 六边形公共充电需求敏感性分析；
- 私人充电可用性变化对公共热点的影响讨论；
- 论文方法演示和模型流程验证。

当前数据不适用于：

- 声称魏都区真实拥有多少私人充电桩；
- 逐小区供配电容量核算；
- 真实峰值负荷、收入、电费或设备投资测算；
- 定位具体住户、车位或私人充电桩；
- 替代物业、电网公司、车管部门或运营平台数据。

最值得补充的校准数据依次为：

1. 魏都区或街道级新能源汽车私人乘用车保有量；
2. 住宅小区固定车位率、私人桩报装量和报装受限原因；
3. 匿名化私人桩充电开始时间、持续时间和单次电量样本。
