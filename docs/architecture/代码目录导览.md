# 代码目录导览

需要改功能时，先按下面的入口表找文件。当前前端按业务归组，后端继续使用 FastAPI 与 PostGIS；原有未提交修改保留在工作区。

```text
src/
├─ main.js                    加载公共样式并挂载 App
├─ App.vue                    登录、会话恢复、页面导航与权限入口
├─ app/navigation.js          地址与工作台的对应关系
├─ features/
│  ├─ map/                    地图页面与搜索、定位、测距、图层
│  │  ├─ MapView.vue          连接地图、工具和规划工作台
│  │  ├─ api/                地图基础数据与 POI 搜索请求
│  │  ├─ components/         图层管理界面
│  │  ├─ composables/        各工具的状态、事件与清理
│  │  └─ config/             底图、渲染样式、图层名称与图例
│  ├─ planning/
│  │  ├─ components/         总览、选址、方案推演、影响报告与车网面板
│  │  ├─ composables/        建站草稿与分析运行状态
│  │  └─ models/             功能区、需求、评分与服务影响计算
│  ├─ stations/models/       站点坐标、属性可信度、设备资料与地图符号
│  ├─ carbon/                双碳界面、状态和计算模型
│  └─ auth/                  登录弹窗与会话模型
├─ shared/
│  ├─ api/                   统一 API 地址、Cookie 请求与 GeoJSON 校验
│  ├─ components/            图标和术语提示
│  ├─ content/               术语定义
│  └─ layout/                顶部导航、可调整分栏与容器
├─ styles/                   公共、规划、工作区和登录样式
└─ legacy/                   已下线车主端、三维演示和未接入组件

tests/frontend/              Node 前端测试
tests/backend/               Python 后端单元测试
tests/integration/           连接真实服务与数据库的检查脚本
tests/fixtures/              前后端共用测试样本
scripts/data/                历史离线采集与预处理
scripts/checks/              目录引用检查和测试启动入口
backend/sql/                 数据库 SQL 文件
docs/reports/                实验验收与数据核查记录
docs/archive/                历史说明，不作为当前实现依据
```

## 修改功能时从哪里开始

| 想修改的部分 | 入口文件 | 负责的内容 |
| --- | --- | --- |
| POI 建议、防抖、清空、历史 | `src/features/map/composables/useStationSearch.js` | 输入到查询、结果选择和卸载清理 |
| POI API 参数与返回值 | `src/features/map/api/poiSearch.js` | `q` 请求、WGS84 数据转地图 Feature |
| POI 数据库搜索 | `backend/poi_search.py` | 正式空间表、名称模糊查询、只读列表 |
| 搜索框与定位后弹窗 | `src/features/map/MapView.vue` | 连接搜索状态、显示转换、`flyTo` 和 Popup |
| 地图颜色、符号、叠放顺序 | `src/features/map/config/mapStyle.js` | MapLibre sources 与 layers |
| 图层菜单与图例名称 | `src/features/map/config/mapLayers.js` | 开关初值、分类与图例说明 |
| 底图坐标对齐 | `src/features/map/config/basemaps.js` | WGS84 与显示坐标转换 |
| 手动设备定位 | `src/features/map/composables/useMapLocation.js` | 浏览器定位、位置标记与释放 |
| 测距 | `src/features/map/composables/useMapMeasure.js` | 点击取点、双击结束、监听清理 |
| 候选编号与最近站连线 | `src/features/map/composables/useSitingMap.js` | 选址地图表现，不计算评分 |
| 时间需求系数与功能区 | `src/features/planning/models/functionalZones.js` | 三个时间场景与需求权重 |
| 候选筛选和评分界面 | `src/features/planning/components/PlannerSiting.vue` | 权重、约束、排序与纳入草稿 |
| 草稿新增、移除、分析失效 | `src/features/planning/composables/useFacilitySandbox.js` | 同一份草稿的状态与重新分析 |
| 登录与地址守卫 | `src/App.vue`、`src/features/auth/models/` | 会话、回跳、跨标签页同步 |

## 搜索的实际执行顺序

```text
① main.js 的 import 加载模块 → createApp(App).mount('#app')
↓
② App 的实例 setup 创建会话与路由状态 → 模板创建 MapView
↓
③ MapView 的实例 setup 调用各 composable，创建本实例的状态
↓ 模板渲染并挂载，onMounted 创建 MapLibre
④ 地图 load 事件触发 → 并行请求五类正式数据；设施目录独立加载
↓ 数据到达后更新图层与 loading 状态
⑤ 用户输入 → useStationSearch 取消旧计时与请求 → 等待 300 ms
├─ 输入法正在组词 → 等 compositionend 后再计时
├─ 空输入 → 清空建议并结束加载
└─ 有关键词 → poiSearch.searchPois → GET /api/pois?q=…
   ↓ await FastAPI → PostGIS 名称查询与研究区检查 → WGS84 坐标数组
⑥ 当前请求返回 → 更新建议列表；迟到、已取消或卸载后的响应被忽略
├─ 空结果 → 显示没有搜索到内容
├─ 接口失败 → 标明仅显示已载入数据中的匹配结果
└─ 用户选择 → 显示坐标转换 → flyTo → Popup 与成功提示
↓
⑦ 离开地图时 onBeforeUnmount：取消请求和计时，移除监听、标记、Popup 与地图
```

模块 `import` 不等于每次组件实例的 `setup`。工具模块导出函数，每次 MapView 实例调用函数时才创建本实例状态。规划模型继续接收正式 WGS84 数据，搜索与底图显示不改变需求权重或建站草稿。

## 常用检查

```powershell
npm test
npm run test:backend
npm run check:structure
npm run build
```

`check:structure` 检查相对导入、文件 URL，以及正式页面是否误引用 `legacy` 页面。原路径对照保存在 [file-moves.json](file-moves.json)。后端入口仍为 `python -m uvicorn backend.main:app --reload`。

此次目录划分参考 [ORBAT Mapper 的业务模块目录](https://github.com/orbat-mapper/orbat-mapper/tree/main/src) 和 [EV 充电站实验项目的页面、组件与状态划分](https://github.com/hanszbh666-lab/Smart-Highway-EV-Charging-Command-Center)。仅参考职责划分，项目算法、依赖和数据口径沿用当前实现。
